# Hafta 2: Python ile Sensör Verisi

## Ne yaptım?
- Linux terminal ve git temel komutlarını kullanarak klasörü ve çalışma dalını oluşturdum.
- Linux ( cd, ls, ls -la, cat, nano, python3) git (status, add,commit -m) komutlarını sıkça kullandım.
- 4 görev sorusu çözdüm. Her görev için terminalde 'nano' kullanarak python dosyaları oluşturdum. Dosya içine kodu yazdıktan sonra kaydedip, kontrol ettim (ex:python3 gorev1.py). Dosyaları çalışma dalına kaydettim. 

## Nerede Takıldım?  
- Görev 3'ü yaparken dosya işlemleri ve os modülünü daha önce kullanmadığım için takıldım. Bu konularda video izleyerek os modülündeki fonksiyonları öğrendim. (makedirs(),mkdir(),removedirs(),rmdir() etc.)
- Görev 3'te son 5 sensör okuması için listeyi bölerken ":" koymam gerektiğini öğrendim. öncesinde hata almıştım. 
- Terminal üzerinden 'nano' ile dosya oluşturmayı, düzenlemeyi ve 'CTRL+0','enter','CTRL+X' gibi kısayolları kullanmayı öğrendim.
