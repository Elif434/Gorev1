## 2. Öğrendiğim komutlar

| Komut | Ne işe yarar |
|-------|--------------|
| `ls` | dosyaları listeler |
| `cd` | klasör değiştirir |
| `cp` | dosyayı ya da klasörleri kopyalar |
| `cat` | dosyanın içeriğini ekrana yazdırır |
| `mv` | dosyayı ya da klasörleri yeniden adlandırır |
| `clear` | terminal ekranındaki önceki yazıları siler |
| `touch` | yeni dosya oluşturur |
| `mkdir` | yeni klasör oluşturur |
| `explorer.exe .` | wsl içinde bulunduğun klasörü windows'un dosya penceresi olarak açar |
| `grep` | dosyanın içinde istediğin kelimeyi bulur |
| `git clone` | github'daki bir projeyi bilgisayara indirir |
| `git --version` | bilgisayarda git programının kurulu olup olmadığını ve sürümünü gösterir |
| `git checkout -b` | branch açar |
| `git push` | kaydedilen değişiklikleri GitHub'daki depoya gönderir|


## 3. Git akışı

```bash
git checkout -b Beyza-hafta1
git add .
git commit -m "hafta1 teslim"
git push origin Beyza-hafta1
```
