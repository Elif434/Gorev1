## 2. Öğrendiğim komutlar

| Komutlar | Ne işe yarar |
|-------|--------------|
| `ls` | Dosyaları listeler |
| `cd` | Klasör değiştirir |
| `mkdir` | Klasör oluşturur |
| `grep` | Metin arar |
| `touch` | boş dosya oluşturur |
| `rm` | klasör siler |
| `rm -rf` | zorla kalıcı silme |
| `cp` | kopyalar |
| `mv` | klasör taşır |
| `cat` | dosya içeriğini yazdırır |
| `sudo` | yönetici yetkisi |
| `apt` | indir kur kaldır güncelle fonk. kullanımını sağlar |
| `clear` | terminali temizler |
| `pwd` | bulunduğun yeri gösterir |

| `kill` | herhangi bir şeyi kapatır |
| `git clone` | repoyu PCye kopyalar |
| `git checkout -b` | yeni branch oluşturur |
| `git status` | dosyaların durumu |
| `git add` | geçici kayıt alanına ekleme |
| `git commit` | 'add' sonrası, lokale kalıcı ekler -m varsa "mesaj" |
| `git push` | 'commit' sonrası, repoya gönderir |
